# Hare - İlmi Lütuf Android Uygulaması (GitHub Actions APK)

Bu depo, `https://hare.ilmilutuf.com.tr` web platformunun yerel özelliklerle güçlendirilmiş Android uygulamasıdır.

## GitHub Üzerinden Otomatik APK Alma

1. Bu depodaki dosyaları yeni bir GitHub deposuna yükleyin.
2. GitHub deponuzda **Actions** sekmesine tıklayın.
3. Otomatik başlayan **Hare Android APK CI/CD** iş akışının tamamlanmasını bekleyin (yaklaşık 2-3 dakika).
4. İşlem tamamlandığında sayfanın altındaki **Artifacts** bölümünden:
   - `Hare-IlmiLutuf-Release-APK` (İmzalı, optimize edilmiş doğrudan kurulabilir sürüm)
   - `Hare-IlmiLutuf-Debug-APK` (Geliştirici / test sürümü)
   paketlerinden birini indirip Android telefonunuza kurun.
